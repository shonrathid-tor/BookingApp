# 🛎️ BookingApp

A simple command-line booking application written in **Go (Golang)**. Users can book event tickets, view remaining tickets, and simulate a basic reservation system—all from the terminal.

## 🚀 Features

- Take user input via CLI
- Validate user input (name, email, ticket quantity)
- Track and update available tickets
- Store bookings in memory
- Welcome message and booking confirmation
- Uses Goroutines to simulate background confirmation sending

## 🛠️ Tech Stack

- **Go (Golang)** – Core application logic
- **Goroutines** – For asynchronous ticket confirmation
- **Standard I/O** – For CLI input/output
